# Third-party resources

The MIT license in this repository covers the EpiCoGE software. Downloaded datasets,
structures and pretrained language-model parameters retain their own terms.

| Resource | Role | Upstream source |
|---|---|---|
| AsEP v1.2.0 | Official samples, split assignments, antibody embeddings, candidate maps and labels | https://doi.org/10.5281/zenodo.11495514 |
| AsEP dataset interface | Dataset documentation and citations; not bundled | https://github.com/biochunan/AsEP-dataset |
| AntiBERTy | Frozen 512-dimensional antibody representations distributed in the official AsEP cache | https://github.com/jeffreyruffolo/AntiBERTy |
| ESM2 / fair-esm | Frozen antigen representations from esm2_t33_650M_UR50D, layer 33 | https://github.com/facebookresearch/esm |
| Biopython | Structure parsing and Shrake–Rupley SASA | https://biopython.org/ |
| Clustal Omega 1.2.4 | Alignment of structure residues to the official sequence axis | http://www.clustal.org/omega/ |

Consult the upstream repositories and dataset record for their licenses and citation
instructions. No third-party model weights or raw structure dataset is redistributed here.
